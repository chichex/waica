# Every archetype package exports a standard ArchetypeManifest

The base `ArchetypeManifest` shape (id, label, default scenes, registry, palette, prefabs, art, `entityIcons`, bindings, `actionLabels`, bundle) moves from the editor into `@waica/engine`, and every `@waica/archetype-*` package exports its manifest under the conventional name `ARCHETYPE`. The package root enriches it as `BrowserArchetypeManifest` with `artUrls`; the `/manifest` subpath omits those browser URLs while its registry resolves stock URIs to package-relative `assets/` paths. Both entry points are plain-Node-loadable. “Node-safe” means free of asset-module imports, not runtime-free: registry component classes intentionally load engine and behavior dependencies. Consumers (editor, MCP) resolve archetypes generically through this contract, so a new archetype works in the editor and with agents without changing either. Rejected alternative: each consumer assembling the manifest from per-archetype named exports (`PLATFORMER_*`), as the editor did — that hardcodes the archetype list and makes every new archetype a coordinated release across all consumers.
